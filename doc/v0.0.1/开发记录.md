# v0.0.1 开发与验证记录

验证日期：2026-11-02。

## 已实现内容

- README 改为 Zhuandown 项目介绍，更新仓库和贡献链接，保留 Typedown 来源、版权及实际工程路径。
- Mermaid 从锁定的 8.14.0 升级为固定版本 12.2.0，改用公开包入口。
- 预览与导出共用串行渲染入口，每次任务一起初始化主题并等待 SVG 完成，继续保持严格安全级别。
- 预览通过块版本、节点身份、主题和实例状态丢弃过期结果；空块、删除块、切换文档及错误恢复均不被旧结果覆盖。
- 主题更新触发编辑器重绘，事件随编辑器实例销毁而解绑。
- 导出等待每个图表完成，单个错误图不阻断正文或其他图表；使用代码节点的文本内容保留源码字符，并始终清理临时容器。
- 页眉页脚模板单独清洗后插入已处理的正文，避免再次清洗破坏 Mermaid SVG 的 HTML 标签和样式。

## 必要构建适配

保留原有 CRA、webpack 及单 chunk 配置，仅处理实际复现的问题：

1. 将 webpack 注入的 `process/browser` 路径改为 `process/browser.js`，修复严格 ESM 解析时的模块定位失败。
2. 旧 Terser 5.10.0 无法解析新版依赖中的类静态初始化块，使用 Yarn resolutions 固定为 5.51.2。
3. 真实浏览器验证发现旧 webpack 未正确改写静态初始化块里的导入引用，运行时报 `__name is not defined`。仅对 Mermaid 和 Mermaid parser 的发布目录增加 Babel 静态初始化块转换，显式声明已使用的 Babel 插件依赖。
